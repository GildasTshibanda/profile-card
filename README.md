
# Card Profile - Gildas Tshibanda

Une carte de visite numérique interactive, moderne et responsive.

Ce projet met en avant une interface épurée orientée Android/Kotlin, intégrante des animations fluides et un design en glassmorphism.

## Fonctionnalités

Design Glassmorphic & Sombre : Interface élégante avec effets de transparence, bordures subtiles et lueur verte Android (Android Glow).

Animations GSAP & Motion Design :

Logo Android animé en filigrane en arrière-plan.

Animation d'apparition séquentielle au chargement de la page.

Effet interactif Tilt 3D réagissant aux mouvements de la souris.

Bouton d'enregistrement vCard : Génère et télécharge instantanément un fichier de contact .vcf sur le téléphone ou l'ordinateur.

Partage Rapide : Utilise l'API Web Share native sur mobile ou copie le lien directement dans le presse-papier.

Badge de statut dynamique : Indicateur de disponibilité animé.

Design Responsive : Optimisé pour tous les écrans (mobiles, tablettes et ordinateurs).

## Technologies Utilisées

HTML5 & CSS3

Tailwind CSS (via CDN) – Stylisation rapide et responsive.

JavaScript (ES6+) – Logique pour la génération vCard, le presse-papier et l'effet Tilt.

GSAP (GreenSock Animation Platform) – Animations Motion Design.

FontAwesome v6 – Icônes vectorielles.

Google Fonts – Typographie Plus Jakarta Sans.
